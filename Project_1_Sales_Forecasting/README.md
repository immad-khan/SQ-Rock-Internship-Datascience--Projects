# Sales Forecasting System

## Overview
This project uses Machine Learning to predict future sales based on historical data.

## Features
- Time-series analysis
- Random Forest prediction model
- Interactive Gradio UI
- Sales trend visualization

## How to Use
1. Adjust the "Days to Forecast" slider (1-365 days)
2. Click "Generate Forecast"
3. View predictions and model metrics

## Model Performance
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score: Measures model accuracy

## Technologies
- Python, Pandas, NumPy
- Scikit-learn (Random Forest)
- Matplotlib, Seaborn
- Gradio
