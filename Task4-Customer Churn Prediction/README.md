# 👥 Customer Churn Prediction

## Overview
Predict customer churn risk using machine learning classification.

## Features
- 🎯 Churn probability prediction
- 📊 Risk assessment visualization
- 💡 Retention recommendations
- 📈 Customer segmentation

## How to Use
1. Enter customer information
2. Select service details
3. Click "Predict Churn"
4. Review risk level and recommendations

## Risk Levels
- **High (>60%)**: Immediate action needed
- **Medium (40-60%)**: Monitor closely
- **Low (<40%)**: Standard care

## Technologies
- Python, Scikit-learn
- Random Forest Classifier
- Matplotlib, Gradio
