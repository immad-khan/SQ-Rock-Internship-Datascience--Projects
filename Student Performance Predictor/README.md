#  Student Performance Predictor

## Overview
ML model that predicts student's final marks based on academic metrics.

## Features
-  Accurate performance prediction
-  Interactive input interface
-  Feature importance analysis
-  Personalized recommendations

## How to Use
1. Enter study hours (0-12 hours/week)
2. Input attendance percentage (0-100%)
3. Provide previous exam score (0-100)
4. Enter assignment score (0-100)
5. Click "Predict Performance"

## Model Details
- Algorithm: Random Forest Regressor
- Accuracy: R² = {r2_score}
- Mean Absolute Error: {mae}

## Technologies
- Python, Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Gradio
